# 🌉 Setu

**Setu** is a dual-app ecosystem designed to bridge the gap between NGOs and volunteers through **data-driven impact, smart coordination, and real-time collaboration**.

It consists of:
- 📊 **setu_ngo** → NGO Dashboard & Data Platform  
- 🤝 **setu_partners** → Volunteer Engagement App  

---

## 🚀 Problem

Local NGOs collect valuable data through surveys, reports, and field work, but this data is:

- Scattered across formats (Excel, forms, paper)
- Stored in isolated systems
- Hard to analyze collectively  

This makes it difficult to:
- Identify urgent community needs  
- Allocate resources efficiently  
- Connect volunteers to the right opportunities  

---

## 💡 Solution

Setu provides a **two-sided platform** that connects NGOs and volunteers using a shared data-driven system.

- NGOs upload and manage data  
- System generates insights and priority areas  
- Volunteers discover and join meaningful campaigns

# 🏢 setu_ngo (NGO App)

A powerful platform for NGOs to manage data, campaigns, and insights.

## ✨ Features

### 📥 Data Collection & Upload
- Upload Excel / CSV files  
- Built-in forms for structured data  
- Local processing → insights generation  

### 📊 Analytics Dashboard
- Issue trends  
- High-need areas  
- Resource gaps  
- Data-driven decision making  

### 📢 Campaign Management
- Create campaigns with:
  - Location  
  - Volunteers required  
  - Schedule  
- Track participation  

### 🧠 Smart Insights
- Identify priority zones  
- Analyze patterns from data  

### 🔐 Verification System
- NGO document verification  
- Trust-based system  

### 📶 Offline Support
- Data collection without internet  
- Auto-sync when online

# 🤝 setu_partners (Volunteer App)

A simple and engaging app for volunteers to discover and participate in impact-driven activities.

## ✨ Features

### 🔍 Campaign Discovery
- Explore campaigns by category  
- Personalized suggestions  

### 📍 Heatmap View
- View high-impact areas  
- See where help is needed most  

### 📝 Issue Reporting
- Report real-world problems  
- Contribute to central data system  

### ✅ Easy Participation
- One-click campaign join  
- Real-time updates  

### 🏆 Profile & Gamification
- Track participation history  
- Earn badges & certificates  
- View personal impact

# 🧠 Core Differentiator

Setu is not just a platform — it is a **data intelligence system**:

- Aggregates NGO + user data  
- Identifies urgent problems  
- Matches:
  - Volunteer interests  
  - Location  
  - NGO needs

# 🛠️ Tech Stack

- **Frontend:** Flutter

- **Data Processing:** Local parsing (CSV/Excel)  
- **Visualization:** Charts + Maps  
- **Storage:** Firestore (processed insights only)
